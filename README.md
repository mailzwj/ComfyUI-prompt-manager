# ComfyUI Prompt Manager（提示词助手）

ComfyUI 提示词模板管理插件。不在画布上添加任何节点，而是在操作栏提供一个"提示词助手"按钮，打开全屏模态框管理带变量的提示词模板，填写变量后一键复制合并结果。

## 功能

- **模板管理**：新建、编辑、删除（二次点击确认，3 秒内未确认自动取消）
- **导入 / 导出**："新建模板"为下拉菜单（表单输入 / 导入），可从 JSON 文件导入模板（按 id 合并）；列表态"导出"按钮将全部模板保存为 `prompt-manager-{YYYY}-{MM}-{DD}-{hh}-{mm}-{ss}.json`
- **变量占位符**：模板内容中用 `{{{变量名}}}` 标记需要填写的部分，保存前实时预览提取到的变量
- **应用模板**：为每个变量生成一个输入框，下方实时显示合并后的提示词（绿色 = 已填值，黄色 = 未填变量），一键复制
- **快速复制**：模板卡片上的"复制"按钮直接复制模板原文
- **使用场景说明**：每个模板可附一段适用场景描述，在列表卡片和应用视图中展示

## 安装

1. 将整个 `ComfyUI-prompt-manager` 目录复制到 ComfyUI 的 `custom_nodes/` 下
2. 重启 ComfyUI
3. 浏览器 **Ctrl+F5** 强制刷新页面（前端扩展无需额外安装）

要求较新版本的 ComfyUI：支持 V3 自定义节点入口（`comfy_entrypoint`）及操作栏按钮扩展（`actionBarButtons`）。插件无画布节点，Python 侧仅有一个空的扩展入口用于满足加载器契约。

## 使用

1. 点击操作栏的"提示词助手"图标按钮（30×30，深色底白色图标），打开全屏模态框
2. 模态框只能通过右上角关闭按钮关闭，关闭后恢复画布
3. **列表视图**：显示全部模板卡片（名称、更新时间、场景说明、变量标签），每个卡片右侧为 应用 / 复制 / 编辑 / 删除 四个小号按钮；工具栏"＋ 新建模板"下拉选择 表单输入（打开新建表单）或 导入（选择 JSON 文件，按 id 合并入库），"导出"下载全部模板的 JSON 文件
4. **表单**：
   - 模板名称（必填）
   - 提示词内容（必填，变量写成 `{{{变量名}}}`，例如 `一只{{{动物}}}站在{{{场景}}}`）
   - 使用场景说明（选填）
5. **应用视图**：点击卡片上的"应用"进入；填写各变量后，未填的变量在复制结果中保留原占位符文本；无变量的模板可直接复制

## 数据存储

模板保存在浏览器 `localStorage`，键为 `comfyui-prompt-manager.templates.v1`。数据仅存在于当前浏览器：更换浏览器、设备或清除站点数据会丢失模板；不随工作流保存，也不经过 ComfyUI 服务端。

## 项目结构

```
ComfyUI-prompt-manager/
├── __init__.py      # V3 入口（comfy_entrypoint），无节点
└── web/
    └── index.js     # 全部前端逻辑：操作栏按钮 + 模态框 + 样式
```
